# Artist Collage Web

Public discovery layer for Artist Collage: landing page, artist directory, shareable profiles, OTP entry, and a studio profile editor.

Requires the API running at `http://localhost:8000`.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open http://localhost:3000

Dev OTP code is `123456` (shown on the sign-in screen when the API is in debug mode).
